# FiYDoc Design System & Tokens

Extracted from the official FiYDoc logo branding and modern healthcare design guidelines.

## Color Palette

### Primary Brand Colors
- **Teal Primary**: `#00B39B` (Doctor 'Y' Icon, Primary Brand Accent)
  - `teal-50`: `#F0FAF8`
  - `teal-100`: `#E0F7F4`
  - `teal-500`: `#00B39B`
  - `teal-600`: `#009E88`
  - `teal-700`: `#008C7A`
  - `teal-900`: `#004F45`

- **Royal Blue**: `#1E58C8` ('FiYDOC' Wordmark, Primary Action Buttons, Active Navigation)
  - `blue-50`: `#F4F8FE`
  - `blue-100`: `#EEF4FF`
  - `blue-500`: `#1E58C8`
  - `blue-600`: `#1846A3`
  - `blue-700`: `#15429B`
  - `blue-900`: `#0C265B`

- **Navy Stethoscope Accent**: `#0F2454`
  - Deep dark contrast for stethoscope elements, clinical headers, and dark mode bases.

### Neutral Colors
- `slate-50`: `#F8FAFC` (App background light)
- `slate-100`: `#F1F5F9` (Card light border/fill)
- `slate-200`: `#E2E8F0` (Input border)
- `slate-400`: `#94A3B8` (Muted / Placeholder text)
- `slate-600`: `#475569` (Body text / secondary)
- `slate-900`: `#0F172A` (Primary text heading)

### Medical Status Tokens
- **Success / Verified**: `#10B981` (Mint Emerald)
- **Warning / Action Required**: `#F59E0B` (Warm Amber)
- **Error / Rejected / SOS**: `#EF4444` (Vibrant Coral Red)
- **Info / Pending OCR**: `#6366F1` (Indigo Blue)

## Typography & Radius
- **Font Stack**: System default font with bold headings (`font-bold`, `font-semibold`) and clean body (`font-normal`).
- **Border Radius**:
  - Small (`rounded-lg`): 8px
  - Medium (`rounded-xl`): 12px
  - Large / Card (`rounded-2xl`): 16px
  - Extra Large / Modal (`rounded-3xl`): 24px
  - Pill (`rounded-full`): 9999px

## Elevations & Glassmorphism
- Subtle backdrop blur (`backdrop-blur-md`), elevated shadows (`shadow-sm`, `shadow-md`, `shadow-lg`).
